อสมการเชิงเส้นและอสมการพหุนาม

พิชิตช่วงคำตอบอสมการขั้นสูงด้วยเทคนิคเส้นจำนวนและวิธี Wavy-Line แบบเซียน สอวน.

1. เทคนิคเส้นจำนวน (Wavy-Line Method)

เมื่อเจออสมการพหุนามดีกรีสูง เช่น \((x - 1)(x - 2)(x - 3) > 0\) เรามีขั้นตอนการหาช่วงคำตอบที่รวดเร็วและแม่นยำดังนี้:

$$\text{ขั้นตอน Wavy-Line: แยกตัวประกอบ ➔ ลงจุดบนเส้นจำนวน ➔ วาดคลื่นจากขวาไปซ้าย (+ เริ่มจากขวาบน)}$$
📺 คลิปติวแนะนำ: สรุปอสมการพหุนาม & เทคนิค Wavy-Line Method

เจาะลึกการแก้ช่วงคำตอบอสมการดีกรีสูงระดับแข่งขัน (โดยช่อง TUENONG)

▶ ไปดูคลิปติวโจทย์
✅ กฎเหล็กในการพิจารณาเครื่องหมาย:
  • สัมประสิทธิ์หน้า \(x\) ทุกวงเล็บ ต้องเป็นบวก (+) เสมอ ถ้าติดลบต้องดึงเครื่องหมายลบออกก่อน
  • เส้นคลื่นจะเริ่มวาดจาก **ขวาบนลงล่างสลับบวก-ลบ (+, -, +, -)** เสมอ
  • ถ้าเจอรากซ้ำคู่ (เช่น \((x-2)^2\)) เส้นคลื่นจะไม่ตัดแกน (เด้งกลับทางเดิม)
⚠️ ข้อควรระวังในอสมการเศษส่วน:
  • ถ้าเป็นอสมการเศษส่วน \(\frac{P(x)}{Q(x)} > 0\) ห้ามนำตัวส่วนคูณไขว้เด็ดขาด เพราะไม่รู้ว่าตัวส่วนเป็นบวกหรือลบ ให้ใช้สมบัติ \(\frac{P(x)}{Q(x)} > 0 \iff P(x)Q(x) > 0\) แทน!

2. 🧪 ห้องทดลอง: เครื่องมือจำลองช่วงคำตอบอสมการกำลังสอง

ลองใส่ค่าราก \(r_1\) และ \(r_2\) (สมมติให้ \(r_1 < r_2\)) ของอสมการในรูป \((x - r_1)(x - r_2) < 0\):

3. ตะลุยโจทย์แนวข้อสอบ สอวน.

ระดับพื้นฐาน • อสมการพหุนาม

โจทย์ข้อที่ 1

จงหาเซตคำตอบของอสมการ: \(x^2 - 5x + 6 \leq 0\)

  1. แยกตัวประกอบพหุนามทางซ้ายมือ:
    \((x - 2)(x - 3) \leq 0\)
  2. หาจุดวิกฤตบนเส้นจำนวนโดยให้แต่ละวงเล็บเท่ากับศูนย์ จะได้จุด \(x = 2\) และ \(x = 3\)
  3. วาดเส้นจำนวนและลงจุด \(2\) กับ \(3\) (ใช้จุดทึบเพราะมีเครื่องหมาย \(\leq\))
  4. ใส่เครื่องหมายช่วงจากขวาไปซ้ายด้วย \(+, -, +\):
    • ช่วง \(x > 3\): เป็นบวก (+)
    • ช่วง \(2 \leq x \leq 3\): เป็นลบ (-)
    • ช่วง \(x < 2\): เป็นบวก (+)
  5. เนื่องจากโจทย์ต้องการช่วงน้อยกว่าหรือเท่ากับศูนย์ (\(\leq 0\)) จึงเลือกช่วงที่เป็นลบ (-)
  6. สรุปเซตคำตอบ: ช่วงปิด \([2, 3]\) หรือเขียนเป็นเซตคือ \(\{x \mid 2 \leq x \leq 3\}\)
ระดับ สอวน. ค่าย 1 • อสมการเศษส่วนพหุนาม

โจทย์ข้อที่ 2

จงหาเซตคำตอบของอสมการ: \(\frac{x - 1}{x + 2} > 0\)

  1. แปลงอสมการเศษส่วนให้อยู่ในรูปผลคูณด้วยสมบัติ \(\frac{P(x)}{Q(x)} > 0 \iff P(x)Q(x) > 0\):
    \((x - 1)(x + 2) > 0\) (โดยมีเงื่อนไขตัวส่วนห้ามเป็นศูนย์คือ \(x \neq -2\))
  2. หาจุดวิกฤตบนเส้นจำนวน: \(x = 1\) และ \(x = -2\)
  3. ลงจุดบนเส้นจำนวน (ใช้จุดโปร่งเพราะไม่มีเครื่องหมายเท่ากับ และตัวส่วนห้ามเป็นศูนย์เด็ดขาด)
  4. ใส่เครื่องหมายช่วงจากขวาไปซ้ายด้วย \(+, -, +\):
    • ช่วง \(x > 1\): เป็นบวก (+)
    • ช่วง \(-2 < x < 1\): เป็นลบ (-)
    • ช่วง \(x < -2\): เป็นบวก (+)
  5. เนื่องจากโจทย์ต้องการช่วงมากกว่าศูนย์ (\(> 0\)) จึงเลือกช่วงที่เป็นบวก (+)
  6. สรุปเซตคำตอบ: \((-\infty, -2) \cup (1, \infty)\)
