พหุนามและการแยกตัวประกอบขั้นสูง

ยกระดับทักษะพหุนามจากห้องเรียนสู่สนาม สอวน. ด้วยทฤษฎีบทเศษเหลือและการจัดรูปสมการขั้นเทพ

1. ทฤษฎีบทเศษเหลือ (Remainder Theorem)

ปกติเวลาเราหารพหุนามด้วยพหุนามดีกรีหนึ่ง เช่น \(x - c\) เราต้องตั้งหารยาวซึ่งเสียเวลามาก ทฤษฎีบทเศษเหลือ จะช่วยให้เราหาเศษจากการหารได้ทันทีโดยไม่ต้องหารเลยครับ!

$$\text{เศษเหลือจากการหารพหุนาม } P(x) \text{ ด้วย } (x - c) \text{ จะเท่ากับ } P(c)$$
📺 คลิปติวแนะนำ: ทฤษฎีบทเศษเหลือ & ขั้นตอนวิธีการหาร

เจาะลึกเทคนิคการทำโจทย์พหุนามระดับแข่งขัน (โดยช่อง WE BY THE BRAIN)

▶ ไปดูคลิปติวโจทย์
✅ ตัวอย่างการใช้งาน:

ถ้าต้องการหาเศษเหลือเมื่อหาร \(P(x) = x^3 - 2x^2 + 5x - 7\) ด้วย \(x - 2\)

ให้แทนค่า \(x = 2\) ลงใน \(P(x)\):
\(P(2) = (2)^3 - 2(2)^2 + 5(2) - 7 = 8 - 8 + 10 - 7 = \mathbf{3}\)
ดังนั้นเศษเหลือคือ \(3\) ทันที!

💡 กรณีตัวหารเป็น \(ax - b\):

ถ้าหารด้วย \(ax - b\) ให้แทนค่า \(x = \frac{b}{a}\) นั่นคือเศษเหลือคือ \(P\left(\frac{b}{a}\right)\)

2. ทฤษฎีบทตัวประกอบ (Factor Theorem)

ต่อยอดจากทฤษฎีบทเศษเหลือ ถ้าเราแทนค่าแล้วเศษเหลือเป็น \(0\) แปลว่าพหุนามนั้นหารลงตัวพอดีเป๊ะ กลายเป็นตัวประกอบทันที:

$$(x - c) \text{ เป็นตัวประกอบของ } P(x) \iff P(c) = 0$$

นี่คืออาวุธหลักที่เราใช้แยกตัวประกอบพหุนามดีกรี 3 หรือดีกรี 4 ขึ้นไป โดยการเดาตัวประกอบ \(c\) จากตัวหารของพจน์ค่าคงที่ตัวสุดท้าย แล้วใช้การหารสังเคราะห์ลดดีกรีลงมาครับ!

3. 🧪 ห้องทดลอง: เครื่องคำนวณค่าพหุนามและเศษเหลืออัตโนมัติ

ลองใส่สัมประสิทธิ์ของพหุนามดีกรี 3 ในรูป \(Ax^3 + Bx^2 + Cx + D\) และค่า \(c\) ที่ต้องการทดสอบหารด้วย \(x - c\):

4. ตะลุยโจทย์แนวข้อสอบ สอวน.

ระดับพื้นฐาน • ทฤษฎีบทเศษเหลือ

โจทย์ข้อที่ 1

กำหนดให้ \(P(x) = x^3 + kx^2 - 5x + 6\) ถ้าหาร \(P(x)\) ด้วย \(x - 2\) แล้วเหลือเศษ \(12\) จงหาค่าของ \(k\)

  1. จากทฤษฎีบทเศษเหลือ การหาร \(P(x)\) ด้วย \(x - 2\) จะเหลือเศษเท่ากับ \(P(2)\)
  2. แทนค่า \(x = 2\) ลงใน \(P(x)\):
    \(P(2) = (2)^3 + k(2)^2 - 5(2) + 6\)
    \(P(2) = 8 + 4k - 10 + 6 = 4k + 4\)
  3. โจทย์กำหนดว่าเศษเหลือเท่ากับ \(12\) ดังนั้นจับเท่ากับ \(12\):
    \(4k + 4 = 12\)
    \(4k = 8 \implies \mathbf{k = 2}\)
ระดับ สอวน. ค่าย 1 • แยกตัวประกอบดีกรี 3

โจทย์ข้อที่ 2

จงแยกตัวประกอบของพหุนาม \(P(x) = x^3 - 6x^2 + 11x - 6\)

  1. หาตัวประกอบที่เป็นไปได้ของพจน์ค่าคงที่ \(-6\) ซึ่งได้แก่ \(\pm 1, \pm 2, \pm 3, \pm 6\)
  2. ลองแทนค่า \(x = 1\):
    \(P(1) = 1^3 - 6(1)^2 + 11(1) - 6 = 1 - 6 + 11 - 6 = 0\)
  3. เนื่องจาก \(P(1) = 0\) แสดงว่า \((x - 1)\) เป็นตัวประกอบหนึ่งของ \(P(x)\)
  4. ใช้การหารสังเคราะห์ลดดีกรีด้วย \(1\):
    สัมประสิทธิ์: \(1, -6, 11, -6\) หารด้วย \(1\) จะได้ผลหารเป็นพหุนามดีกรีสอง: \(x^2 - 5x + 6\)
  5. แยกตัวประกอบพหุนามดีกรีสองต่อ: \(x^2 - 5x + 6 = (x - 2)(x - 3)\)
  6. สรุปคำตอบ: \(P(x) = (x - 1)(x - 2)(x - 3)\)
