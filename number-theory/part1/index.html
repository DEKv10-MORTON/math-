การหารลงตัว หร.ม. และขั้นตอนวิธีของยุคลิด

ปูพื้นฐานจากศูนย์ให้เด็ก ม.2 เข้าใจภาษาคณิตศาสตร์ระดับแข่งขัน พร้อมเทคนิคหา หร.ม. เลขหลักล้านใน 5 วินาที

1. การหารลงตัว (Divisibility) คืออะไร?

ในชั้นเรียนปกติ เราเขียนว่า \(12 \div 3 = 4\) แต่ใน สอวน. เราจะเปลี่ยนมาใช้สัญลักษณ์เส้นตั้งตรงแบบนี้ครับ:

$$a \mid b \quad \text{อ่านว่า "a หาร b ลงตัว"}$$

หมายความว่า มีจำนวนเต็ม \(k\) ที่ทำให้ \(b = a \cdot k\) (โดยที่ \(a \neq 0\))

✅ ตัวอย่างที่ถูก:
  • \(3 \mid 12\) เพราะ \(12 = 3 \times 4\)
  • \(-5 \mid 20\) เพราะ \(20 = (-5) \times (-4)\)
  • \(7 \mid 0\) เพราะ \(0 = 7 \times 0\) (ศูนย์หารด้วยอะไรก็ลงตัว ยกเว้น 0)
❌ จุดที่เด็ก ม.2 ชอบสับสน:
  • \(12 \mid 3\) ผิด! (ต้องเอาตัวหารไว้ข้างหน้า ตัวตั้งไว้ข้างหลัง)
  • \(0 \mid 5\) ผิด! (ห้ามเอา 0 เป็นตัวหารเด็ดขาด)

🔑 4 สมบัติไม้ตายที่ใช้พิสูจน์ข้อสอบ สอวน.

1. สมบัติการถ่ายทอด: ถ้า \(a \mid b\) และ \(b \mid c\) แล้ว \(a \mid c\)
2. สมบัติการคูณเพิ่ม: ถ้า \(a \mid b\) แล้ว \(a \mid bc\) (คูณอะไรเข้าไปข้างหลังก็ยังหารลงตัว)
3. สมบัติการรวมร่าง (Linear Combination): ถ้า \(a \mid b\) และ \(a \mid c\) แล้ว \(a \mid (bx + cy)\) เสมอ (ไม่ว่า \(x, y\) จะเป็นจำนวนเต็มบวกหรือลบ!)
4. สมบัติขนาดตัวเลข: ถ้า \(a \mid b\) และ \(b \neq 0\) แล้ว \(\vert{}a\vert{} \le \vert{}b\vert{}\) (ตัวหารไม่มีทางใหญ่กว่าตัวตั้ง)

2. ขั้นตอนวิธีของยุคลิด (Euclidean Algorithm)

ถ้าโจทย์ให้หา หร.ม. ของ \(12\) กับ \(18\) เราคงตั้งหารสั้นได้สบาย แต่ถ้าโจทย์ สอวน. ถามว่า:

"จงหา ห.ร.ม. ของ \(2,479\) และ \(1,843\)"

การนั่งสุ่มหาแม่สูตรคูณมาหารสั้นจะเสียเวลาทำข้อสอบมาก! ยุคลิด (Euclid) จึงคิดค้นทฤษฎีที่บอกว่า:

$$\gcd(a, b) = \gcd(b, r)$$

เมื่อ \(a = bq + r\) (พูดง่ายๆ คือ "ห.ร.ม. ของตัวตั้งกับตัวหาร จะเท่ากับ ห.ร.ม. ของตัวหารกับเศษเหลือเสมอ")

ระดับเริ่มต้น • ใช้สมบัติการรวมร่าง

โจทย์ข้อที่ 1

จงหาจำนวนเต็มบวก \(n\) ทั้งหมด ที่ทำให้ \(n + 2\) หาร \(3n + 17\) ลงตัว (เขียนเป็นสัญลักษณ์คือ \((n+2) \mid (3n+17)\))

แนวคิดหลัก: เราต้องกำจัดตัวแปร \(n\) ออกจากตัวตั้งให้หมด โดยใช้สมบัติ \((a \mid b \text{ และ } a \mid c \implies a \mid (bx + cy))\)

  1. เรารู้ว่าตัวมันเองย่อมหารตัวมันเองลงตัว: \((n+2) \mid (n+2)\)
  2. เอา \(3\) คูณเข้าข้างหลังเพื่อให้มี \(3n\) เหมือนตัวตั้ง: \((n+2) \mid 3(n+2) \implies (n+2) \mid (3n+6)\)
  3. โจทย์กำหนดให้: \((n+2) \mid (3n+17)\)
  4. จับมาลบกันเพื่อกำจัด \(3n\): \((n+2) \mid [(3n+17) - (3n+6)]\)
  5. จะได้ว่า: \((n+2) \mid 11\) (เหลือแต่ตัวเลขเพียวๆ แล้ว!)
  6. ตัวประกอบที่เป็นจำนวนเต็มของ \(11\) มีแค่ \(\pm 1, \pm 11\)
  7. เนื่องจาก \(n\) เป็นจำนวนเต็มบวก ดังนั้น \(n+2 \ge 3\) จึงเหลือแค่กรณีเดียวคือ \(n+2 = 11 \implies \mathbf{n = 9}\)
ระดับ สอวน. ค่าย 1 • ยูคลิดประยุกต์

โจทย์ข้อที่ 2

กำหนดให้ \(n\) เป็นจำนวนเต็มบวก จงหาค่าที่เป็นไปได้ทั้งหมดของ \(\gcd(5n + 3, 2n + 1)\)

แนวคิดหลัก: สมมติให้ \(d = \gcd(5n + 3, 2n + 1)\) แปลว่า \(d\) ต้องหารทั้งสองก้อนนี้ลงตัว

  1. จากนิยาม หร.ม. จะได้ \(d \mid (5n + 3)\) และ \(d \mid (2n + 1)\)
  2. เราอยากกำจัด \(n\) ทิ้ง จึงคูณ \(2\) เข้าก้อนแรก และคูณ \(5\) เข้าก้อนหลัง:
    • \(d \mid 2(5n + 3) \implies d \mid (10n + 6)\)
    • \(d \mid 5(2n + 1) \implies d \mid (10n + 5)\)
  3. จับสองก้อนนี้มาลบกัน: \(d \mid [(10n + 6) - (10n + 5)]\)
  4. จะได้ว่า: \(d \mid 1\)
  5. จำนวนเต็มบวกที่หาร \(1\) ลงตัวมีแค่ตัวเดียวเท่านั้น! ดังนั้น \(\mathbf{\gcd(5n + 3, 2n + 1) = 1}\) เสมอ (เป็นจำนวนเฉพาะสัมพัทธ์กันทุกค่า \(n\))
