สมการไดโอแฟนไทน์เชิงเส้น (Linear Diophantine Equations)

ถอดรหัสสมการตัวแปรสองตัวที่คำตอบต้องเป็น "จำนวนเต็ม" พร้อมเทคนิคการแก้สมการแบบเซียน สอวน.

1. สมการไดโอแฟนไทน์เชิงเส้นคืออะไร?

สมการไดโอแฟนไทน์ (Diophantine Equation) คือสมการพหุนามที่เราสนใจหาคำตอบที่เป็น จำนวนเต็ม (\(\mathbb{Z}\)) เท่านั้น โดยรูปแบบมาตรฐานของสมการเชิงเส้นสองตัวแปรคือ:

$$ax + by = c$$

เมื่อ \(a, b, c\) เป็นจำนวนเต็มที่กำหนดให้ และ \(x, y\) เป็นจำนวนเต็มที่เราต้องหาคำตอบ

📺 คลิปติวแนะนำ: การแก้สมการไดโอแฟนไทน์เชิงเส้น และบทพิสูจน์

ศึกษาทฤษฎีบทและการตรวจสอบเงื่อนไขการมีคำตอบ (โดยช่อง Math and Life)

▶ ไปดูคลิปอธิบาย
✅ เงื่อนไขสำคัญที่ต้องเช็คก่อนทำ:

สมการ \(ax + by = c\) จะมีคำตอบเป็นจำนวนเต็ม ก็ต่อเมื่อ \(\gcd(a, b)\) ต้องหาร \(c\) ลงตัวเป๊ะๆ!

ถ้า ห.ร.ม. ของ \(a\) และ \(b\) หาร \(c\) ไม่ลงตัว แปลว่าสมการนี้ "ไม่มีคำตอบที่เป็นจำนวนเต็ม" ทันที

💡 ตัวอย่างความต่าง:
  • \(2x + 4y = 5\) ➡️ ไม่มีคำตอบจำนวนเต็ม เพราะ \(\gcd(2,4) = 2\) แต่ \(2 \mid 5\) ไม่ลงตัว
  • \(2x + 4y = 6\) ➡️ มีคำตอบ เพราะ \(\gcd(2,4) = 2\) และ \(2 \mid 6\) ลงตัว

2. สเต็ปการหาคำตอบทั่วไป (General Solutions)

หากเราหาคำตอบเฉพาะตัวแรก (Particular Solution) ได้แล้ว สมมติให้เป็น \((x_0, y_0)\) เราจะสามารถสร้างคำตอบทั้งหมดบนโลกใบนี้ได้ด้วยสูตร:

$$x = x_0 + \frac{b}{d} t$$ $$y = y_0 - \frac{a}{d} t$$

เมื่อ \(d = \gcd(a, b)\) และ \(t\) เป็นจำนวนเต็มใดๆ (\(t \in \mathbb{Z}\))

3. 🧪 ห้องทดลอง: เครื่องมือตรวจสอบและหาคำตอบเบื้องต้น

ลองใส่สัมประสิทธิ์ \(a, b, c\) ของสมการ \(ax + by = c\) แล้วระบบจะเช็คเงื่อนไขและคำนวณคำตอบให้ทันที:

4. ตะลุยโจทย์แนวข้อสอบ สอวน.

ระดับพื้นฐาน • ตรวจสอบเงื่อนไขคำตอบ

โจทย์ข้อที่ 1

จงตรวจสอบว่าสมการ \(12x + 18y = 100\) มีคำตอบที่เป็นจำนวนเต็มหรือไม่?

  1. เทียบรูปทั่วไป \(ax + by = c\) จะได้ \(a = 12, b = 18, c = 100\)
  2. หา ห.ร.ม. ของ \(a\) และ \(b\): \(\gcd(12, 18) = 6\)
  3. ตรวจสอบว่า ห.ร.ม. หาร \(c\) ลงตัวหรือไม่: ตรวจสอบว่า \(6 \mid 100\) หรือไม่?
  4. เนื่องจาก \(100 \div 6 = 16\) เหลือเศษ \(4\) (หารไม่ลงตัว)
  5. สรุป: สมการนี้ ไม่มีคำตอบที่เป็นจำนวนเต็ม ครับ!
ระดับ สอวน. ค่าย 1 • หาคำตอบจำนวนเต็มบวก

โจทย์ข้อที่ 2

จงหาจำนวนคู่ลำดับของจำนวนเต็มบวก \((x, y)\) ทั้งหมดที่สอดคล้องกับสมการ \(5x + 7y = 111\)

  1. ตรวจสอบเงื่อนไข: \(\gcd(5, 7) = 1\) และ \(1 \mid 111\) ลงตัว ดังนั้นมีคำตอบแน่นอน
  2. หาคำตอบเฉพาะ (Particular Solution) โดยลองแทนค่าหรือจัดรูป:
    \(5x = 111 - 7y\)
    มองหาค่า \(y\) ที่ทำให้ \(111 - 7y\) หารด้วย \(5\) ลงตัว เช่น ถ้า \(y = 3\) จะได้ \(111 - 21 = 90\) ซึ่ง \(90 \div 5 = 18\)
    ดังนั้นชุดคำตอบเริ่มต้นคือ \(x_0 = 18, y_0 = 3\)
  3. เขียนคำตอบทั่วไปตามสูตร (\(d = 1, a = 5, b = 7\)):
    \(x = 18 + 7t\)
    \(y = 3 - 5t\) เมื่อ \(t \in \mathbb{Z}\)
  4. เนื่องจากโจทย์ต้องการจำนวนเต็มบวก (\(x > 0\) และ \(y > 0\)):
    • \(18 + 7t > 0 \implies 7t > -18 \implies t > -\frac{18}{7}\) (\(t \ge -2\))
    • \(3 - 5t > 0 \implies 5t < 3 \implies t < \frac{3}{5}\) (\(t \le 0\))
  5. ช่วงของค่า \(t\) ที่เป็นไปได้คือ \(-2 \le t \le 0\) ซึ่งมีค่า \(t = -2, -1, 0\) (รวม \(3\) ค่า)
  6. แทนค่า \(t\) กลับไปจะได้ 3 คู่ลำดับ:
    • \(t = -2 \implies (4, 13)\)
    • \(t = -1 \implies (11, 8)\)
    • \(t = 0 \implies (18, 3)\)
  7. สรุป: มีคำตอบที่เป็นจำนวนเต็มบวกทั้งหมด \(3\) คู่

🎯 มินิควิซ: ทดสอบความเข้าใจ
