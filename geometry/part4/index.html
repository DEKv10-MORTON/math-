📈 เรขาคณิต (ตอนที่ 4)
เรขาคณิตวิเคราะห์เบื้องต้น (Coordinate Geometry)

พิชิตสูตรระยะทาง จุดกึ่งกลาง ความชัน และระยะห่างเส้นตรง ฉบับเซียนเตรียมสอบ สอวน.

1. อาวุธหลักในระบบพิกัดฉาก

การแก้ปัญหาเรขาคณิตด้วยพิกัดฉากช่วยให้เราแปลงรูปทรงเรขาคณิตให้อยู่ในรูปสมการพีชคณิต โดยมีสูตรสำคัญที่ต้องท่องจำและใช้งานให้คล่อง:

$$\text{ความชัน (Slope): } m = \frac{y_2 - y_1}{x_2 - x_1} \quad \text{และสมการเส้นตรง: } y - y_1 = m(x - x_1)$$
📺 คลิปติวแนะนำ: สมการเส้นตรงและความชันจาก 0 จนเซียน

ทบทวนเทคนิคการหาความชันและสร้างสมการเส้นตรงอย่างรวดเร็ว (โดยช่อง Mr.Phoops)

▶ ไปดูคลิปติวเส้นตรง
✅ เส้นขนานและเส้นตั้งฉาก:
  • เส้นขนานกัน: ความชันเท่ากัน (\(m_1 = m_2\))
  • เส้นตั้งฉากกัน: ความชันคูณกันได้ \(-1\) (\(m_1 \cdot m_2 = -1\))
💡 ระยะห่างจากจุดไปยังเส้นตรง:
  • ระยะห่างสั้นที่สุดจากจุด \((x_0, y_0)\) ไปยังเส้นตรง \(Ax + By + C = 0\) คือ:
    \(d = \frac{\vert{}Ax_0 + By_0 + C\vert{}}{\sqrt{A^2 + B^2}}\)

2. 🧪 ห้องทดลอง: เครื่องคำนวณระยะทางและความชันระหว่างสองจุด

เมื่อกำหนดพิกัดจุด \(A(x_1, y_1)\) และ \(B(x_2, y_2)\) ระบบจะคำนวณระยะห่าง จุดกึ่งกลาง และความชันให้ทันที:

3. ตะลุยโจทย์แนวข้อสอบ สอวน.

ระดับพื้นฐาน • ระยะทางและจุดกึ่งกลาง

โจทย์ข้อที่ 1

กำหนดให้จุด \(A(-2, 3)\) และ \(B(4, -5)\) เป็นจุดปลายของเส้นผ่านศูนย์กลางของวงกลมวงหนึ่ง จงหารัศมีของวงกลมนี้

  1. เส้นผ่านศูนย์กลางของวงกลมคือระยะห่างระหว่างจุด \(A\) และ \(B\)
  2. คำนวณระยะทาง \(d\) ระหว่าง \((-2, 3)\) กับ \((4, -5)\):
    \(d = \sqrt{(4 - (-2))^2 + (-5 - 3)^2}\)
    \(d = \sqrt{6^2 + (-8)^2} = \sqrt{36 + 64} = \sqrt{100} = 10\) หน่วย
  3. เนื่องจากรัศมี (\(r\)) เท่ากับครึ่งหนึ่งของเส้นผ่านศูนย์กลาง:
    \(r = \frac{10}{2} = \mathbf{5}\) หน่วย
ระดับ สอวน. ค่าย 1 • ระยะห่างระหว่างจุดกับเส้นตรง

โจทย์ข้อที่ 2

จงหาระยะห่างที่สั้นที่สุดจากจุด \(P(2, -1)\)ไปยังเส้นตรงที่ผ่านจุด \(A(1, 2)\) และ \(B(4, 6)\)

  1. หาความชันของเส้นตรงผ่าน \(A(1, 2)\) และ \(B(4, 6)\):
    \(m = \frac{6 - 2}{4 - 1} = \frac{4}{3}\)
  2. หาสมการเส้นตรงผ่านจุด \(A(1, 2)\) ด้วยรูปทั่วไป \(Ax + By + C = 0\):
    \(y - 2 = \frac{4}{3}(x - 1) \implies 3(y - 2) = 4(x - 1)\)
    \(3y - 6 = 4x - 4 \implies 4x - 3y + 2 = 0\) (จะได้ \(A = 4, B = -3, C = 2\))
  3. ใช้สูตรหาระยะห่างจากจุด \(P(2, -1)\) ไปยังเส้นตรง \(4x - 3y + 2 = 0\):
    \(d = \frac{\vert{}4(2) - 3(-1) + 2\vert{}}{\sqrt{4^2 + (-3)^2}}\)
    \(d = \frac{\vert{}8 + 3 + 2\vert{}}{\sqrt{16 + 9}} = \frac{\vert{}13\vert{}}{\sqrt{25}} = \frac{13}{5} = \mathbf{2.6}\) หน่วย

🎯 มินิควิซ: ทดสอบความเข้าใจ

เส้นตรงเส้นหนึ่งผ่านจุด \((2, 3)\) และตั้งฉากกับเส้นตรงที่มีความชันเท่ากับ \(-\frac{2}{3}\) จงหาความชันของเส้นตรงเส้นนี้
